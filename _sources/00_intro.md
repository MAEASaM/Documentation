# Welcome to MAEASaM Project Book

This book provides the openly accessible documentation for the
MAEASaM project. It is intended as a reference for researchers,
collaborators and anyone wishing to understand or reuse the project's
data and resources.

The current release covers the **File Organisation Schema**, which
describes how project files and folders are structured and named.

Further documentation, including the **Metadata Schema**, **Controlled Vocabularies**, **Policies** will be added
in future releases.
